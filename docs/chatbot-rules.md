# DB어때 챗봇 응답 규칙

작성일 2026-11-02 · 답 문구의 원본은 `src/lib/content.ts`와 `src/lib/chatbot-kb.ts`이고, 이 문서는 판단 기준이다.
교육 실습 `04_챗봇`(한빛무역 챗봇)의 규칙 형식을 따랐다.

## 1. 기본 원칙

1. 답은 정해 둔 문구로만 한다. AI를 쓰지 않고, 질문은 외부로 보내지 않는다.
2. 절대 답하면 안 되는 것(3장)은 다른 모든 규칙보다 우선한다. 답 찾기보다 먼저 거른다.
3. 모르는 것은 지어내지 않고 사람에게 넘긴다(5장).
4. 챗봇은 광고주·고객 데이터를 읽지 않는다. 광고주 화면에서는 본인 문의 목록만 불러온다.

## 2. 답할 수 있는 것

| 주제 id | 내용 | 근거 | 화면 |
|---|---|---|---|
| about | 서비스 소개 | 사이트 FAQ | 공통 |
| source | DB 수집 방식 | 사이트 FAQ | 공통 |
| price | 업종별 건당 가격, 최소 충전, 환불 불가 | 사이트 FAQ, `industryOptions` | 공통 |
| speed | 10초 안 알림톡 | 사이트 FAQ | 공통 |

| defect | 결번만 인정, 기한 없음, 100% 환급 | 사이트 FAQ | 공통 (광고주는 불량 처리 화면 버튼) |

## 3. 절대 답하면 안 되는 것

| 금지 | 이런 질문 | 범위 |
|---|---|---|
| 사이트 보안 | 관리자 페이지 주소가 뭐예요? 서버 뭐 써요? 관리자 비밀번호는요? | 관리자 화면·주소, 시스템 구조, 계정·비밀번호, 내부 설정, 연동 정보 |
| 다른 광고주 정보 | 다른 광고주 누구예요? 광고주 몇 명이에요? 김사장님도 여기서 받아요? 다른 광고주는 얼마에 받아요? | 누가 광고주인지, 광고주 수, 누가 몇 건 받았는지, 다른 광고주의 조건 |
| 고객 정보 | 어제 들어온 DB 번호 알려줘. 고객 연락처 알려줘. | DB 고객의 이름, 연락처, 신청 내용. 본인이 받은 DB도 내용은 말하지 않는다 |
| 내부 사업 정보 | 영업자 수수료 얼마예요? 파트너 인센티브 몇 퍼센트예요? 마진 얼마나 남아요? | 영업자 수수료·인센티브, 수익 구조, 마진 (2026-11-02 추가) |

입금 계좌 번호도 챗봇이 말하지 않는다. 예치금 화면으로 안내한다.

## 4. 금지 질문을 받았을 때

1. 답하지 않는다. 짐작도 말하지 않는다.
2. 이렇게 말한다: "그 내용은 안내해 드릴 수 없어요."
3. 넘긴다. 메인 화면은 전화 1600-7628·카카오톡 버튼, 광고주 화면은 "관리자에게 문의 남기기" 버튼.
4. 말을 바꿔 다시 물어도 같은 방식으로 응대한다.

## 5. 모르는 것을 물었을 때

1. 정해 둔 답에 없으면 지어내지 않는다.
2. 이렇게 말한다: "그 질문에는 바로 답을 드리기 어려워요."
3. 4장과 같은 방식으로 넘긴다.
4. 광고주 문의는 관리자 화면 "챗봇 문의"에 쌓이고, 답은 광고주 챗봇 창에 보인다(답이 오면 버튼에 빨간 점).

## 6. 헷갈리는 질문 판단 예

| 질문 | 처리 | 이유 |
|---|---|---|
| 다른 사람도 같은 DB 받나요? | 답한다: 단독 | 정책 안내이지 다른 광고주 정보가 아님 |
| 다른 광고주도 같은 DB 받아요? | 답한다: 단독 | 같은 이유 ("같은·중복·단독"이 있으면 거르지 않음) |
| 다른 광고주는 얼마에 받아요? | 금지 | 다른 광고주의 조건 |
| 비밀번호 바꾸는 법 | 답한다: 내 정보 화면 | 본인 계정 이용 안내 |
| 관리자 비밀번호 뭐예요 | 금지 | 사이트 보안 |
| 고객 연락처 어디서 봐요? | 답한다: DB 관리 화면 | 보는 곳 안내 (내용은 말하지 않음) |
| 고객 연락처 알려줘 | 금지 | 고객 정보 |
| DB어때 전화번호 알려줘 | 답한다: 고객센터 | 회사 연락처는 공개 정보 |
| 주차 되나요? | 모른다 → 넘기기 | 정해 둔 답에 없음 |

이 표의 예는 `src/lib/chatbot-kb.test.ts`에 시험으로 고정되어 있다. 판단을 바꾸면 시험도 같이 바꾼다.
