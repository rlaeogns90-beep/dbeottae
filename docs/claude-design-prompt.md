## 2. VS Code(Claude Code)에 반영할 때 쓰는 프롬프트

Claude 디자인에서 최종본을 내보낸 파일(HTML/React 코드나 링크)을 프로젝트에 넣은 뒤, VS Code의 Claude Code에 아래를 붙여 넣으세요. `[ ]` 부분은 직접 채웁니다.

```
db-eottae 프로젝트(Next.js 15 + Tailwind CSS v4)에 Claude 디자인에서 확정한 디자인을 반영해줘.

- 디자인 파일: [내보낸 파일 경로 또는 링크]
- 반영할 화면: [예: 메인(src/app/login/page.tsx) 먼저, 그다음 광고주 화면]

지켜야 할 것:
1. 화면 모양(레이아웃, 간격, 글자 크기, 색, 컴포넌트 모양)만 바꾸고, 동작 로직은 건드리지 마.
   - src/lib/engine.ts(배정 규칙), src/lib/store.tsx(저장·로그인·승인 등), src/lib/types.ts, src/lib/seed.ts는 수정하지 않는다.
2. 색과 글꼴은 src/app/globals.css의 @theme 토큰(ink, sub, mute, line, soft, page, brand, brand-dark, brand-soft, accent, ok, warn, bad)을 쓴다. 디자인에 새 색이 꼭 필요하면 먼저 알려주고 토큰으로 추가한다.
3. 공통 부품은 src/components/ui.tsx, contact.tsx(전화·카카오·하단 사업자 정보), live-feed.tsx, shells.tsx(화면 틀)를 고쳐서 쓴다. 같은 부품을 새로 또 만들지 않는다.
4. 문구는 디자인 파일을 따르되, 가격·정책 숫자(40,000원 VAT 별도, 실제 차감 44,000원, 하루 3건, 3시간, 24시간, 10초, 11,000원)가 다르면 반영하지 말고 나에게 물어본다.
5. 휴대폰(390px)과 PC(1440px)에서 가로 스크롤이 생기지 않게 한다.
6. 끝나면 npx tsc --noEmit 과 npx eslint src 를 돌리고, 개발 서버에서 바뀐 화면을 확인한 다음, 무엇을 바꿨는지 화면별로 정리해줘.
7. 회의용 공유 페이지도 갱신하려면 node artifact/build.mjs 로 다시 빌드한다.
```
