## 3. 누가 무엇을 묻나

1. **처음 온 영업사원 (비로그인)**: 가격, 단독 여부, 결번 환급, 가입 방법, 업종 → 가입 신청으로 유도
2. **광고주 (로그인)**: "내 잔액 얼마?", "오늘 몇 건 받았어?", "수신 왜 꺼졌어?", "충전 어떻게?", "결번 신청 어디서?"
3. **영업자(파트너)**: 내가 데려온 광고주 현황 → 지금 화면으로 충분, 챗봇 대상에서 제외

## 4. 단계별 계획

### 1단계 · 자주 묻는 질문 챗봇 (초안 완성, 브랜치 `feat/site-chatbot`)
- 첫 페이지 오른쪽 아래 "궁금한 점 물어보기" 버튼
- 빠른 질문 버튼 4개 + 직접 입력 → 단어로 맞는 답 찾기
- 답이 없으면 전화 1600-7628 / 카카오톡 채널 버튼
- 비용 0원, 외부로 아무것도 보내지 않음, 보안 정책 변경 없음
- 남은 일: 문구 차이 정리 반영, 휴대폰 화면 확인, 배포

### 2단계 · AI 상담 (Claude)
- 고객 질문 → 우리 서버 `/api/chat` → Claude API → 답
  (사이트 보안 정책상 브라우저가 외부에 직접 연결할 수 없어서 서버를 거친다)
- 답의 근거는 위 정책 문구만. 모르는 것은 "고객센터로 연결해 드릴게요"로 답하게 지시
- 가격·환급처럼 돈 관련 답은 정책 문구를 그대로 인용
- 남용 방지: 기존 요청 제한 기능(`overLimit`) 사용, 한 사람당 하루 질문 수 제한
- 필요: Anthropic API 키(Vercel 환경변수), 월 비용 예상 1~3만 원 (하루 질문 100개 이하 기준, 추정)

### 3단계 · 로그인 광고주 도우미
- 광고주 화면(`/app`)에도 챗봇 버튼
- 본인 정보만 답: 예치금 잔액, 오늘 받은 건수/3건, 수신 상태와 꺼진 이유, 최근 불량 신청 결과
- 이미 있는 로그인 확인과 데이터(`loadState`)를 쓰므로 새 저장소 불필요
- 충전·불량 신청은 챗봇이 직접 처리하지 않고 해당 화면으로 바로 가는 버튼만 제공

### 4단계 · 상담 남기기와 관리자 알림
- 챗봇에서 "상담 요청" → 이름·연락처 받기 → 관리자 화면에 쌓고 알림톡(SOLAPI)으로 알림
- 개인정보 수집 동의 문구 추가 필요 (개인정보처리방침 갱신)
- 챗봇에서 자주 나온 질문을 관리자 화면에서 보고 FAQ에 반영
