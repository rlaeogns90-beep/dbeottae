# DB어때 수정사항 설계: DB 현황 검색, 알림톡 정리, 상담 메모 기록 (2026-11-02)

## 1. 무엇을, 왜

대표님 수정 요청 6가지.

**관리자**
1. DB 현황(`/admin`)에 접수 날짜 필터와 검색(이름, 연락처, 차종)을 넣는다. DB가 쌓이면 특정 고객을 찾기 어렵다.
2. 알림톡 설정에서 "고객센터"를 "챗봇 문의"로 바꾼다. 고객센터가 챗봇으로 바뀌었기 때문.
3. 알림톡 템플릿
   - 3-1. 충전 완료(광고주용)는 그대로. "처리 알림"(관리자용)은 이름을 "관리자 확인 안내"로 바꾼다.
   - 3-2. 잔여 수량 안내(광고주용, 새로): 구매 가능한 DB가 1건 남았을 때.
   - 3-3. 소진 안내(광고주용, 새로): 예치금이 소진됐을 때.

**광고주**
4. DB 상세에서 상담 메모를 저장하면 입력칸 아래에 기록이 쌓인다.
5. 고객을 누르지 않아도 목록에 최근 메모가 보인다.

## 2. 정해진 것 (대표님 결정, 2026-11-02)

| 항목 | 결정 |
|---|---|
| 메모 방식 | 저장할 때마다 시간과 함께 기록이 쌓이고, 입력칸은 비워진다 |
| 최근 메모 표시 | DB 관리 목록과 광고주 홈 "최근 받은 DB" 둘 다 |
| 소진 기준 | 남은 예치금이 1건 값보다 적어 수신이 자동으로 꺼지는 순간 |
| 날짜 필터 | 시작일~종료일 + 빠른 버튼(오늘, 어제, 최근 7일, 이번 달) |

## 3. 어떻게

### 3.1 DB 현황 검색·날짜 필터
- 검색창 하나: 이름, 연락처, 차종에 들어 있으면 보인다. 연락처는 숫자만 비교(하이픈 무시).
- 날짜: 접수 시각(`createdAt`)을 한국 날짜로 바꿔 시작일~종료일(양 끝 포함) 비교. 빠른 버튼은 날짜 칸을 채운다.
- 기존 필터(페이지, 사이트, 상담 상태)와 함께 쓰이고, "필터 초기화"에 포함된다.
- 화면에만 있는 기능이라 서버·저장 데이터는 바뀌지 않는다.

### 3.2 알림톡 이름 정리
- 처리 알림 구분 `support`의 이름: "고객센터 문의"/"고객센터" → "챗봇 문의" (`TASK_LABEL`, 설정 화면 `TASK_NAME`). 알림톡 변수 `구분`에 들어가는 글자도 바뀐다(변수라 카카오 재검수 불필요).
- "처리 알림" → "관리자 확인 안내": 설정 화면의 칸 이름, 상태 목록, 시험 발송 버튼, 설명 문구. 저장 필드 이름(`templateTask`)은 그대로 둔다(저장된 값 유지).

### 3.3 새 알림톡 2개
- 설정에 템플릿 ID 칸 2개 추가: `templateRemain`(잔여 수량 안내), `templateEmpty`(소진 안내). 비어 있으면 보내지 않는다.
- 보내는 시점: DB가 배정되어 문의 접수 알림톡을 보낸 직후(웹훅 자동 배정, 관리자 직접 배정 두 곳 모두).
  - 그 광고주의 남은 구매 가능 건수 = ⌊잔액 ÷ 업종 1건 금액(VAT 포함)⌋
  - 안내 종류는 배정을 저장하는 순간의 상태로 계산한다(동시 접수 때 중복·누락 방지).
  - 수신이 자동으로 꺼졌으면(`offBy: "auto"`) → 소진 안내
  - 아니고 남은 건수가 정확히 1이면 → 잔여 수량 안내
  - 차감은 1건씩이라 같은 안내가 연달아 가지 않는다. 충전 후 다시 1건이 되면 다시 간다.
- 변수: `광고주명`, `잔액`(예: 44,000원), `남은건수`(예: 1건), `url`(예치금 화면).
- 시험 발송 버튼 2개 추가(기존 시험 발송과 같은 방식).
- 템플릿 문구 초안은 `docs/alimtalk-templates.md`에 쓴다. 카카오 검수 후 ID를 넣으면 발송된다.

### 3.4 상담 메모 기록
- 배정 건(`Assignment`)에 `memos: { at: string; text: string }[]`를 더한다. 기존 `memo`는 "가장 최근 메모"로 계속 채워서 엑셀 받기와 기존 화면이 그대로 동작한다.
- 새 동작 `addMemo { id, text }`: 본인 배정 건에만, 1~2,000자, 기록은 최대 50개(데이터 크기 때문에 검토 후 200→50). 앞쪽(최신)에 추가하고 `memo`도 같은 글로 바꾼다.
- 이전에 저장된 `memo`가 있고 `memos`가 비어 있으면, 화면에서는 그 글을 시각 없는 "이전 메모" 한 줄로 보여준다. 첫 기록을 저장할 때 그 글을 시각 없이 기록 맨 뒤에 넣어 지워지지 않게 한다.
- 관리자 화면 데이터에는 `memos`를 보내지 않는다(최근 메모 `memo`만). 영업자에게는 둘 다 보내지 않는다.
- DB 상세: 입력칸 + "메모 저장" → 입력칸 비움, 아래에 최신순 목록(시각 + 글).
- 목록 줄(`LeadRow`): 차종 줄 아래에 최근 메모 한 줄(말줄임). 메모가 없으면 줄을 그리지 않는다.

## 4. 하지 않을 것
- 메모 수정·삭제 (요청 없음).
- 관리자 화면의 광고주 메모 보기 (요청 없음).
- 템플릿 카카오 등록·검수 (대표님이 솔라피에서 진행).

## 5. 확인 방법
- DB 현황: 날짜 범위·빠른 버튼·검색(이름, 하이픈 있는/없는 연락처, 차종)이 맞게 걸러지는지, 필터 초기화.
- 알림톡: 설정 화면 이름이 바뀌었는지, 새 칸 저장되는지. 남은 건수 계산을 시험 코드로 고정(2건→1건 잔여, 1건→0건 소진, 3건→2건 없음).
- 메모: 저장하면 쌓이고 입력칸이 비는지, 새로고침 후에도 남는지, 목록과 홈에 최근 메모가 보이는지, 이전 메모가 보이는지, 휴대폰 폭.
