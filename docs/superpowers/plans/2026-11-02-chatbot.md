# DB어때 상담 챗봇 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 메인 화면과 광고주 화면 오른쪽 아래에 정해 둔 답만 쓰는 챗봇을 두고, 광고주 화면의 고객센터를 챗봇 문의(관리자 답변 + 빨간 점)로 바꾼다.

**Architecture:** 답 찾기는 브라우저 안의 순수 함수 모듈(`src/lib/chatbot-kb.ts`)이 한다. 금지 질문 거르기 → 정해 둔 답 찾기 → 사람에게 넘기기 순서. 광고주 문의는 기존 `/api/support`와 `support_posts` 표를 그대로 쓰고, 읽음 표시용 열 하나와 `seen` 동작 하나만 더한다.

**Tech Stack:** Next.js 15 (App Router), React 19, Tailwind 4, Neon Postgres(`@neondatabase/serverless`), lucide-react. 테스트는 새 설치 없이 기존 devDependency `esbuild`로 묶어 Node 24 내장 `node:test`로 돌린다.

**Spec:** `docs/superpowers/specs/2026-11-02-chatbot-design.md`

## Global Constraints

- AI·외부 서비스 연결 없음. 챗봇은 `/api/support` 말고는 아무 데도 요청하지 않는다 (CSP `connect-src 'self'`).
- 새 패키지 설치 금지 (설치가 필요하면 대표님께 먼저 묻는다).
- 화면 문구와 코드 주석은 한국어. 주석은 지금 코드처럼 짧게, 왜를 적는다.
- 결번 신청: **기한 없음**. "3시간"이라는 말을 챗봇·FAQ 어디에도 쓰지 않는다.
- 최소 충전: **업종별 10건분** — 신차 장기렌트 440,000원, 오토바이 매매 165,000원 (VAT 포함). 숫자는 `industryOptions`의 price로 계산한다 (`price × 1.1 × 10`), 문구에 직접 쓰지 않는다.
- 하루 최대 수신: **광고주 1명당 하루 최대 3건**. 사이트 FAQ에도 넣는다.
- 금지 거절 문장(정확히): `그 내용은 안내해 드릴 수 없어요.`
- 못 찾을 때 문장(정확히): `그 질문에는 바로 답을 드리기 어려워요.` 뒤에 화면별 넘기기 (메인: 전화 1600-7628·카카오톡 버튼 / 광고주: "관리자에게 문의 남기기" 버튼).
- 입금 계좌 번호는 챗봇 답에 넣지 않는다. 예치금 화면 버튼으로 안내한다.
- 챗봇은 광고주·고객 데이터(`state.leads`, `state.assignments`, `state.advertisers`, `state.wallet`)를 읽지 않는다.
- 메인 화면 질문은 저장하지 않는다.
- 질문 입력 200자 제한, 문의 확인 칸은 1,000자 제한.

## Review Focus

1. 금지 단어와 정상 질문이 겹치는 경우 — "다른 사람도 같은 DB 받나요?", "다른 광고주도 같은 DB 받아요?"는 단독 FAQ로 답해야 하고, "비밀번호 바꾸는 법"은 내 정보 안내로 답해야 한다. (Task 2 테스트에 고정)
2. 관리자가 이미 단 답을 **수정**한 경우 — 광고주가 앞서 읽었더라도 빨간 점이 다시 떠야 한다 (`seen_at < reply_at`). (Task 3 테스트에 고정)
3. 휴대폰 폭 광고주 화면 — 챗봇 버튼과 창이 아래 메뉴 막대(약 64px + 안전영역)를 가리지 않는다. (Task 5 확인 단계)
4. 로그인이 풀린 상태에서 문의 보내기 — 401이면 "다시 로그인해 주세요."를 챗봇 말풍선으로 보여주고 입력한 글은 지우지 않는다. (Task 5 확인 단계)
5. 문의 1시간 10건 제한(`overLimit`)에 걸린 경우 — 429 응답 문구를 말풍선으로 보여주고 전화·카톡 버튼을 함께 준다. (Task 5 확인 단계)
