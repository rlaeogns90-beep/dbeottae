# DB어때 알림톡 템플릿 (솔라피 등록용)

작성일 2026-11-02. 솔라피 → 카카오 알림톡 템플릿에 등록하고, 검수가 끝나면 템플릿 ID를
관리자 화면 **외부 연동 · 알림톡 → 솔라피 알림톡**의 해당 칸에 넣고 저장한다. 칸이 비어 있으면 보내지 않는다.

변수 이름(`#{...}`)은 아래와 글자까지 똑같아야 한다. 사이트가 이 이름으로 값을 채워 보낸다.

## 1. 잔여 수량 안내 (광고주용, 새로 등록)

- 보내는 때: DB를 받고 나서 구매 가능한 DB가 **1건** 남았을 때 (한 번)
- 관리자 화면 칸: `잔여 수량 안내 템플릿 ID (광고주용)`

```
[DB어때] 예치금 잔여 수량 안내

#{광고주명}님, 현재 예치금으로 받을 수 있는 DB가 #{남은건수} 남았습니다.

- 남은 예치금: #{잔액}

예치금을 모두 사용하면 수신이 자동으로 꺼집니다.
끊김 없이 DB를 받으시려면 미리 충전해 주세요.
```

버튼(웹링크): `예치금 충전하기` → `https://#{url}`

## 2. 소진 안내 (광고주용, 새로 등록)

- 보내는 때: DB를 받고 나서 예치금이 1건 금액보다 적어져 **수신이 자동으로 꺼졌을 때**
- 관리자 화면 칸: `소진 안내 템플릿 ID (광고주용)`

```
[DB어때] 예치금 소진 안내

#{광고주명}님, 예치금이 소진되어 DB 수신이 자동으로 꺼졌습니다.

- 남은 예치금: #{잔액}

충전이 확인되면 다시 수신을 켜고 DB를 받으실 수 있습니다.
```

버튼(웹링크): `예치금 충전하기` → `https://#{url}`

## 3. 기존 템플릿

| 화면 이름 | 대상 | 변경 |
|---|---|---|
| 문의 접수 | 광고주 | 없음 |
| 통계 알림 | 관리자 | 없음 |
| 관리자 확인 안내 (예전 이름: 처리 알림) | 관리자 | 화면 이름만 변경. 템플릿 ID 그대로. `#{구분}` 값이 "고객센터 문의"에서 "챗봇 문의"로 바뀜(변수라 재검수 불필요) |
| 충전 완료 | 광고주 | 없음 |

카카오에 등록된 템플릿 이름도 "관리자 확인 안내"로 바꾸고 싶으면 새 템플릿으로 다시 등록해야 한다(이름 변경은 재검수). 필수는 아니다.
